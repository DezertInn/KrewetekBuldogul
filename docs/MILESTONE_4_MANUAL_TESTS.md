# Milestone 4 — scenariusze testów manualnych

Wersja: fragment B01, 2026-10-10. Wyniki automatyczne i materiały znajdują się w [raporcie M4](MILESTONE_4_VALIDATION.md). Udany test M3 zgłoszony przez użytkownika jest wcześniejszą obserwacją; nie zastępuje wykonania poniższych scenariuszy. Wygląd i balans nowych przeciwników pozostają regulowane.

Uruchom production preview zgodnie z [README](../README.md), otwórz <http://127.0.0.1:4173/>, wybierz **Boxing gym · M4**, broń i Begin. Domyślne: WASD — ruch, mysz — celowanie, LPM — atak, Space — dash, R — przeładowanie, E — interakcja, Esc — pauza. Używaj aktualnych podpowiedzi po remapowaniu. Zapisz commit, system, przeglądarkę, rozdzielczość i profil sterowania. Każdy scenariusz oznacz PASS/FAIL/BLOCKED, nie odhaczaj niewykonanego sprzętu.
